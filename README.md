# 🚌 Real Time Bus Ticket Booking Management System

A Python-based console application for managing bus reservations in real time.

## 📌 Features
- View available buses & routes
- Real-time seat availability tracking
- Book & cancel tickets
- Search passenger records
- Revenue & booking summary reports

## 🛠️ Tech Stack
- Python 3.x
- Concepts: Functions, Dictionaries, OOP, Exception Handling

## ▶️ How to Run
```bash
python bus.py
```

## 📸 Output
Menu-driven console interface with 9 options including booking, cancellation, and reports.
